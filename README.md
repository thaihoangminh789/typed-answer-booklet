# Typed answer booklet (published site)

Built and pushed by `_Kit/booklet.py` in the private `students-kit` repository: do not edit here.
The app's source is `students-kit/_Kit/booklet/`; how it works: `students-kit/_Kit/docs/booklet.md`.

- `index.html`, `assets/`: the built app (Vite + Tiptap + MathLive).
- `w/<CODE>-<random>.json`: worksheets for students (questions only; never answers).
- `worksheets/`: samples. Open one with `?ws=worksheets/sample.json`.
